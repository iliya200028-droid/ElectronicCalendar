# Электронный календарь

Дипломный проект на Java.

## Возможности

- Регистрация и авторизация пользователей
- Редактирование профиля
- Безопасное хранение паролей
- Календарь с режимами день, неделя, месяц
- Создание, изменение и удаление событий
- Напоминания о событиях
- Управление задачами, приоритетами и статусами
- Поиск и фильтрация по датам и категориям
- Сохранение информации в SQLite

## Используемые технологии

Java 21, JavaFX, Maven, SQLite, JUnit 5.

## Запуск проекта

Требуется JDK 21 и Maven.

В папке проекта выполнить:

mvn javafx:run

## Тестирование

mvn test

## Хранение данных

В Windows база данных сохраняется в папке:

%APPDATA%\ElectronicCalendar

## Готовое приложение

Приложение также собрано в виде переносимой
Windows-версии ElectronicCalendar.exe.
Для запуска необходима вся папка сборки.
